Panduan Mail Merge

Mail merge (gabungan surat / surat massal) adalah fitur Microsoft Word untuk menghasilkan banyak surat dengan tampilan yang sama tetapi isi yang berbeda untuk setiap penerima — nama, alamat, jabatan, dan data lain diambil otomatis dari sebuah daftar (umumnya file Excel). Anda cukup menulis satu dokumen induk berisi penanda, lalu Word membuat satu surat untuk setiap baris data.

Apa itu Mail Merge?

Konsep dasar beserta contoh dokumen induk dan hasilnya.

Definisi

Mail merge adalah proses menggabungkan sebuah dokumen utama yang formatnya tetap dengan sebuah sumber data yang isinya berubah-ubah, sehingga menghasilkan sekumpulan dokumen yang dipersonalisasi. Setiap baris pada sumber data menghasilkan satu surat.

Word menandai bagian yang berubah dengan merge field (field gabungan). Saat penggabungan dijalankan, Word mengisi field tersebut dengan data dari sumber data.

Ilustrasi: dokumen induk → hasil

Dokumen induk (yang Anda tulis):

  Kepada:
  «Nama» «Nama Belakang»
  «Alamat»
  «Kota» «Kode Pos»

  Yth. «Sapaan» «Nama Belakang»,
  Terima kasih atas partisipasi Anda ...
Hasil untuk baris pertama:

  Kepada:
  Ahmad Fauzi
  Jl. Malioboro No. 1
  Yogyakarta 55213

  Yth. Bapak Fauzi,
  Terima kasih atas partisipasi Anda ...

Kapan Sebaiknya Dipakai?

  • Surat undangan ke banyak peserta dengan nama dan alamat berbeda.
  • Sertifikat, piagam, dan penghargaan per nama peserta.
  • Label alamat dan amplop untuk pengiriman massal.
  • Email massal yang disapa secara pribadi per penerima.
  • Tagihan, notifikasi, atau direktori berisi data per orang atau per item.

⚠️ Mail merge bukan untuk mengirim surat yang isinya sama persis tanpa personalisasi. Jika isinya identik, cukup cetak satu dokumen berkali-kali. Kekuatan mail merge justru terletak pada variasi data per penerima.

Komponen Utama Mail Merge

Tiga bagian yang selalu ada pada setiap penggabungan surat.

📄

1. Dokumen Induk

Main document berisi teks dan format yang sama untuk semua penerima: kop surat, isi, tanda tangan, dan penutup. Bagian yang berubah digantikan oleh merge field.

🗂️

2. Sumber Data

Data source berisi daftar penerima: satu baris per orang, satu kolom per informasi (Nama, Alamat, Kota, Kode Pos, dan seterusnya). Dapat berupa Excel, Outlook, Access, atau daftar baru di Word.

🏷️

3. Merge Field

Field gabungan adalah penanda seperti «Nama» di dalam dokumen induk. Saat digabungkan, Word menggantinya dengan nilai dari kolom yang bersesuaian.

📌 Alur singkat: tulis dokumen induk → hubungkan sumber data → sisipkan merge field → pratinjau hasil → cetak/simpan. Seluruh proses ini dijalankan dari tab Mailings di Word.

Menyiapkan Sumber Data di Excel

Kualitas data menentukan kualitas hasil mail merge. Rapikan daftar sebelum digabungkan.

Aturan Dasar Daftar Penerima

  • Baris pertama = header kolom (Nama, Alamat, Kota, Kode Pos, dan sebagainya).
  • Satu baris = satu penerima. Jangan menggabungkan dua orang dalam satu baris.
  • Satu kolom = satu informasi. Hindari menaruh nama dan alamat pada sel yang sama.
  • Letakkan seluruh data pada satu lembar kerja (satu sheet), tanpa sel gabungan (merge cell).
  • Jangan ada baris atau kolom kosong di tengah tabel, dan jangan ada baris judul tambahan di atas header.

Contoh tabel data_penerima.xlsx

Nama;Alamat;Kota;Kode Pos
Ahmad Fauzi;Jl. Malioboro No. 1;Yogyakarta;55213
Siti Rahma;Jl. Pemuda No. 20;Surabaya;60271
Budi Santoso;Jl. Asia Afrika No. 5;Bandung;40111

✅ Simpan file di komputer lokal atau folder berbagi. Word tidak dapat memakai sumber data yang tersimpan di alamat web (HTTP) sebagai sumber mail merge.

Hal yang Paling Sering Menyebabkan Masalah

  • Nol di depan hilang — kode pos seperti 00399 berubah menjadi 399. Format kolom sebagai Text.
  • Format persentase mengalikan nilai dengan 100. Jika tidak diinginkan, format kolom persentase sebagai teks.
  • Angka desimal & mata uang perlu format kolom yang tepat (Number/Currency) agar tampil rapi di surat.
  • Tanggal dapat berubah format; pastikan format tanggal sumber sudah sesuai keinginan.

Jika Sumber Data Berupa CSV/TXT

Impor dulu ke Excel melalui Data → From Text/CSV. Pada pratinjau impor, atur kolom kode pos menjadi Text, lalu pilih Load.

Langkah Mail Merge di Microsoft Word

Panduan langkah demi langkah untuk Word versi Windows, dari membuat dokumen induk sampai mencetak.

  1. Siapkan dokumen induk & pilih jenis surat Buka dokumen kosong di Word, lalu buka tab Mailings → Start Mail Merge → pilih Letters. Ini menandai dokumen sebagai surat massal.
  2. Hubungkan sumber data (daftar penerima) Bukti tab Mailings → Select Recipients → Use an Existing List, lalu pilih file Excel penerima. Pada dialog yang muncul, pilih sheet yang berisi data dan biarkan Cell Range kosong, kemudian klik OK.

    💡 Anda juga dapat memilih Type a New List untuk mengetik daftar langsung di Word, atau Choose from Outlook Contacts untuk memakai kontak Outlook.

  3. Tulis isi surat Ketik teks surat yang sama untuk semua penerima: kop, pembuka, isi, penutup, dan tanda tangan. Sisakan tempat di mana nama dan alamat akan dimasukkan (langkah berikutnya).
  4. Sisipkan merge field Letakkan kursor di posisi yang diinginkan, lalu buka Mailings → Address Block untuk blok alamat. Pilih format nama pada dialog Insert Address Block, lalu klik OK. Untuk salam pembuka, gunakan Mailings → Greeting Line dan pilih formatnya. Untuk field lain (mis. nomor invoice), pakai Insert Merge Field.

    📌 Saat belum digabungkan, field tampil sebagai «Nama», «Alamat», dan seterusnya. Ini normal — hasil sebenarnya terlihat setelah pratinjau.

  5. Pratinjau hasil Klik Mailings → Preview Results untuk melihat surat yang sudah terisi. Gunakan tombol Next dan Previous (atau kotak nomor record) untuk berpindah antar penerima dan memastikan nama serta alamat tampil benar. Klik Preview Results lagi untuk kembali ke tampilan field.
  6. Selesaikan & gabungkan Buka Mailings → Finish & Merge, lalu pilih salah satu: Edit Individual Documents (periksa/ubah tiap surat), Print Documents (cetak langsung), atau Send Email Messages (kirim sebagai email).

⚠️ Periksa hasil pada langkah pratinjau sebelum mencetak, khususnya spasi ganda, field kosong (penerima tanpa alamat), dan pemenggalan baris. Lebih mudah membetulkan dokumen induk daripada menyunting ratusan surat hasil.

Menyimpan & Menggunakan Ulang

Dokumen mail merge tetap terhubung dengan daftar penerima sehingga dapat dipakai lagi.

Menyimpan Dokumen

  1. Simpan dokumen Gunakan File → Save. Hubungan ke daftar penerima ikut tersimpan bersama dokumen.
  2. Buka kembali kapan saja Saat dokumen mail merge dibuka lagi, Word menanyakan apakah koneksi ke sumber data dipertahankan. Pilih Yes.

Kebiasaan Baik

  • Simpan dokumen induk dan file data penerima di lokasi yang tetap agar tautan tidak putus.
  • Simpan salinan master sumber data; perbarui data di file yang sama, bukan membuat file baru setiap kali.
  • Ganti nama file hasil gabungan dengan jelas (mis. surat_undangan_hasil.docx) agar tidak menimpa dokumen induk.
  • Uji dulu dengan sedikit baris data (2–3 penerima) sebelum menjalankan daftar besar.

Tips & Masalah Umum

Kendala yang sering ditemui saat mail merge dan cara mengatasinya.

🔢 Data & Format

  • Nol di depan hilang (00399 → 399): format kolom kode pos sebagai Text di Excel.
  • Persentase berlipat 100: format persentase dapat mengalikan nilai; jadikan teks bila ingin nilai tetap.
  • Simbol mata uang hilang: tambahkan simbol (mis. Rp) pada dokumen induk di sekitar merge field.
  • Angka jadi notasi ilmiah pada nomor panjang: jadikan kolom sebagai teks sebelum digabungkan.

📄 Dokumen & Field

  • Field tampil sebagai «Nama»: wajar sebelum penggabungan; gunakan Preview Results untuk melihat hasil.
  • Alamat tidak lengkap: gunakan Address Block, atau susun sendiri dengan Insert Merge Field per kolom.
  • Spasi/baris ganda: periksa dokumen induk, karena field kosong dapat menyisakan baris kosong.
  • Penerima tertentu tidak boleh dicetak: gunakan Edit Recipient List untuk menghapus centang penerima.

🗂️ Sumber Data

  • Word tidak menemukan data: pastikan data berada di satu sheet dengan header di baris pertama.
  • Hanya sebagian data terbaca: hilangkan baris/kategori kosong dan sel gabungan di tengah tabel.
  • Sumber data di cloud/web: simpan salinan ke komputer lokal atau folder berbagi sebelum dipakai.
  • Data .txt/.csv: impor dulu ke Excel (Data → From Text/CSV) lalu jadikan sumber mail merge.

🔍 Verifikasi Cepat

  • Jalankan pratinjau untuk beberapa penerima pertama, tengah, dan terakhir.
  • Perhatikan penerima tanpa alamat atau dengan data kosong.
  • Untuk daftar besar, gunakan Edit Individual Documents lalu periksa sekilas sebelum mencetak.
  • Simpan versi master sumber data agar mudah diperbarui untuk pengiriman berikutnya.
