Format Data Tabel Paling Sederhana

Panduan CSV

CSV (Comma-Separated Values) adalah format file teks murni yang menyimpan data berbentuk tabel (baris dan kolom) dengan tanda pemisah tertentu, umumnya koma (,) atau titik-koma (;). Karena isinya teks biasa, CSV dapat dibuka dan diedit di aplikasi apa pun — dari Notepad hingga Microsoft Excel — dan menjadi jembatan paling umum untuk memindahkan data antar program dan sistem.

Teks Murni

CSV tidak menyimpan format, rumus, warna, atau gambar — hanya teks dengan pemisah. Karena itu ukurannya kecil dan mudah diproses program.

🔗

Universal

Dibaca oleh Excel, Google Sheets, Python (pandas), R, basis data (SQL), hingga aplikasi ERP — menjadikannya format pertukaran data de facto.

🧱

Struktur Sederhana

Baris pertama biasanya berisi judul kolom (header), baris berikutnya berisi data. Tiap baris = satu record, tiap pemisah = batas kolom.

Apa itu CSV?

Struktur dasar file CSV beserta aturan penulisannya.

Contoh isi file data_mahasiswa.csv

Nama;NIM;Kota;IPK
Ahmad Fauzi;2201001;Yogyakarta;3,75
Siti Rahma;2201002;Surabaya;3,92
Budi Santoso;2201003;Bandung;3,58

📌 Baris pertama adalah header (judul kolom), tiga baris berikutnya adalah record data. Pada contoh ini pemisahnya titik-koma karena bilangan desimal memakai koma.

Aturan Dasar Penulisan CSV

  • Satu baris = satu record. Baris dipisahkan oleh karakter baris baru.
  • Pemisah antar kolom harus konsisten di seluruh file (koma atau titik-koma, jangan dicampur).
  • Kutipan ganda (") digunakan bila nilai mengandung pemisah, tanda kutip, atau baris baru: "Nama, Gelar";2026.
  • Baris kosong sebaiknya dihindari; beberapa program menganggapnya record kosong.
  • Spasi di sekitar pemisah menjadi bagian dari data, mis. Nama ;IPK menghasilkan kolom berisi Nama .

Jenis Pemisah: Koma atau Titik-Koma

Pemisah kolom CSV ditentukan oleh konvensi regional (setting bahasa), bukan oleh isi datanya.

Mengapa Bisa Berbeda?

Di negara-negara berbahasa Inggris (dan Indonesia dengan setting regional English (United States)), pemisah desimal adalah titik (3.75), sehingga koma bebas dipakai sebagai pemisah kolom. Namun di Indonesia dan banyak negara Eropa, pemisah desimal adalah koma (3,75). Karena koma sudah dipakai untuk desimal, pemisah kolom dipindah ke titik-koma (;) agar tidak bentrok.

Aturan praktis: pemisah desimal dan pemisah kolom tidak boleh sama. Jika desimal memakai koma → pemisah CSV adalah titik-koma. Jika desimal memakai titik → pemisah CSV adalah koma.

Pemisah yang Umum Dipakai

PemisahNamaKapan Dipakai
,CommaSetting regional Inggris (desimal titik); standar RFC 4180.
;SemicolonSetting regional Indonesia/Eropa (desimal koma); default Excel versi lokal.
(TAB)Tab-delimitedVarian bernama TSV; umum di data bioinformatika & copy-paste dari Excel.

⚠️ Penting: Excel menyimpan dan membaca CSV mengikuti pengaturan Regional Format di Windows (Control Panel → Region → Additional settings → List separator). Pada Windows berbahasa Indonesia, list separator default adalah titik-koma, sehingga Excel "versi Indonesia" membuat CSV dengan pemisah titik-koma — bukan koma, meskipun ekstensinya .csv. Inilah sumber kebingungan paling umum saat bertukar file CSV.

Membuat CSV di Notepad

Langkah membuat file CSV dari nol hanya dengan Notepad (Windows).

  1. Buka Notepad Tekan Win + R, ketik notepad, lalu Enter. Atau klik kanan di folder tujuan → New → Text Document.
  2. Tulis header & data Ketik judul kolom di baris pertama, lalu data di baris berikutnya. Pisahkan kolom dengan titik-koma (setting Indonesia) atau koma (setting Inggris). Setiap record di baris baru.
  3. Simpan dengan Save As Menu File → Save As. Ubah Save as type menjadi All Files (*.*), lalu beri nama data_mahasiswa.csv (jangan data_mahasiswa.csv.txt).
  4. Pilih encoding UTF-8 Di kotak dialog Save As, pilih Encoding: UTF-8 (bila tersedia pilih UTF-8 with BOM agar Excel mendeteksi karakter non-ASCII dengan benar).

✅ File siap. Buka dengan Excel atau editor teks lain untuk memeriksa hasilnya. Notepad menampilkan CSV apa adanya — sangat berguna untuk memastikan pemisah dan encoding benar.

Contoh yang diketik di Notepad

Nama;NIM;Kota;IPK
Ahmad Fauzi;2201001;Yogyakarta;3,75
Siti Rahma;2201002;Surabaya;3,92
Budi Santoso;2201003;Bandung;3,58

⚠️ Notepad modern menyimpan UTF-8 tanpa BOM. Jika karakter seperti é, ü, atau simbol rupiah tampak berantakan saat dibuka di Excel, simpan ulang dengan Notepad sebagai UTF-8 with BOM, atau impor manual melalui Excel sambil memilih encoding UTF-8 (lihat bagian Impor).

Mengimpor CSV di Excel

Dua cara: buka langsung, atau impor terkontrol melalui Power Query.

Cara 1 — Buka Langsung (Cepat)

  1. Klik dua kali file CSV Atau di Excel: File → Open, pilih file .csv.
  2. Periksa hasilnya Excel membuka CSV langsung ke kolom-kolom. Jika semua data menumpuk di satu kolom, berarti pemisah file tidak cocok dengan list separator regional Excel — pakai Cara 2.

⚠️ Membuka langsung berisiko: angka 001 menjadi 1, tanggal 12/03/2026 ditafsir ulang, dan angka panjang berubah menjadi notasi ilmiah. Jika presisi data penting, gunakan Cara 2.

Cara 2 — Impor Terkontrol (Power Query)

  1. Mulai impor Tab Data → From Text/CSV, pilih file. Muncul pratinjau data.
  2. Atur delimiter & encoding Pilih Delimiter (Comma / Semicolon / Tab) dan File Origin (mis. 65001: Unicode (UTF-8)).
  3. Tentukan tipe kolom Klik kanan kolom → Change Type → Text untuk kolom kode (NIM, kode pos) agar angka nol di depan tidak hilang.
  4. Muat ke sheet Klik Load. Data masuk sebagai tabel Excel. Hasil impor dapat di-refresh jika file sumber berubah.

💡 Untuk kolom yang berisi pemisah desimal asing (mis. CSV dengan titik: 3.75), impor dulu sebagai teks, lalu ganti . menjadi , dengan Find & Replace, baru ubah tipenya menjadi number.

Mengekspor CSV di Excel

Simpan lembar kerja sebagai CSV beserta peringatan yang perlu diketahui.

  1. Buka File → Save As Pilih lokasi, lalu ubah Save as type ke salah satu format CSV.
  2. Pilih format CSV CSV UTF-8 (Comma delimited) (*.csv) — disarankan, mendukung semua karakter. Pilihan CSV (Comma delimited) memakai encoding lokal Windows (ANSI) dan list separator regional.
  3. Konfirmasi peringatan Excel memperingatkan bahwa CSV hanya menyimpan satu sheet aktif dan menghapus rumus (hanya nilainya tersimpan), format, dan gambar. Klik Yes/OK.
  4. Tutup tanpa menyimpan ulang (opsional) Saat menutup file, Excel bertanya apakah menyimpan perubahan ke format .xlsx. Jika ingin mempertahankan file Excel asli beserta formatnya, klik Don't Save.

Perbandingan Format CSV di Excel

FormatEncodingPemisahCatatan
CSV UTF-8 UTF-8 (dengan BOM) Mengikuti list separator regional (koma atau titik-koma) ✅ Pilihan paling aman untuk teks berbahasa Indonesia dan lintas sistem.

📌 Meski namanya "Comma delimited", pada Excel ber-setting Indonesia pemisah aktualnya adalah titik-koma. Periksa file hasil ekspor dengan Notepad untuk memastikan.

Tips & Masalah Umum

Hal-hal yang sering ditemui saat bekerja dengan CSV di Excel dan Notepad.

🔤 Encoding & Karakter

  • Karakter rusak (� / Ã©): file UTF-8 dibaca sebagai ANSI. Impor manual dengan File Origin UTF-8, atau simpan dengan BOM.
  • UTF-8 with BOM menandai file sebagai UTF-8 secara eksplisit — disarankan untuk data Indonesia.
  • Hindari karakter pemisah di dalam data; jika terpaksa, bungkus nilai dengan tanda kutip ganda.

🔢 Angka & Tanggal

  • Nol di depan hilang (001 → 1): impor kolom sebagai Text, jangan General.
  • Koma vs titik desimal: CSV dengan titik desimal dibaca sebagai teks oleh Excel Indonesia. Konversi manual atau ganti list separator.
  • Tanggal berubah (03/04 bisa dibaca 3 April atau 4 Maret): format tanggal CSV tidak menyimpan informasi ambiguitas; tetapkan tipe kolom saat impor.
  • Notasi ilmiah (2.2E+15 pada nomor panjang seperti NIK): atur kolom sebagai teks sebelum data dibaca.

🗂️ Struktur File

  • Header sebaiknya satu baris, tanpa titik, tanpa spasi berlebih, dan unik antar kolom.
  • Hindari baris kosong di tengah file dan kolom kosong yang tidak disengaja.
  • Baris terakhir sebaiknya diakhiri baris baru (beberapa parser mensyaratkannya).
  • Ukuran besar (> 1 juta baris) melebihi batas sheet Excel; gunakan alat lain seperti Python/pandas.

🔍 Verifikasi Cepat

  • Buka CSV di Notepad: terlihat teks murni dengan pemisah — jika terlihat karakter kotak-kotak, cek encoding.
  • Di Excel, gunakan Data → Text to Columns sebagai perbaikan cepat bila kolom menumpuk jadi satu.
  • Hitung kolom baris pertama vs baris lain; jumlah field harus sama di setiap baris.
  • Simpan salinan master di .xlsx, dan hasilkan CSV hanya sebagai format tukar.

Apa itu BOM?

Byte Order Mark — penanda kecil di awal file yang sering menjadi penyebab masalah encoding CSV.

Definisi Singkat

BOM (Byte Order Mark) adalah penanda opsional berupa urutan byte khusus di awal sebuah file teks yang memberi tahu program pembaca bahwa file tersebut memakai encoding Unicode tertentu. Untuk UTF-8, BOM berupa tiga byte: EF BB BF (satu karakter U+FEFF). BOM bukan bagian dari data — ia "meta-informasi" yang menempel di depan data.

Nama "Byte Order Mark" berasal dari perannya pada UTF-16/UTF-32: urutan byte menandai endianness (big-endian atau little-endian). Pada UTF-8 endianness tidak relevan, tetapi BOM tetap dapat ditulis dan dibaca sebagai penanda identitas encoding.

Kenapa Penting untuk CSV?

  • Excel di Windows dapat mendeteksi file CSV ber-encoding UTF-8 dengan benar jika ada BOM; tanpa BOM, Excel sering menganggapnya ANSI dan karakter non-ASCII (mis. é, ü, huruf Arab, atau simbol) tampil rusak.
  • CSV UTF-8 dari Excel ditulis dengan BOM; sedangkan Notepad modern menyimpan UTF-8 tanpa BOM secara default (tersedia opsi "UTF-8 with BOM").
  • Program lain (Python, pandas, database, sistem web) umumnya membaca UTF-8 tanpa masalah, baik ber-BOM maupun tidak — tetapi sebagian parser menganggap BOM sebagai bagian dari nama kolom pertama (mis. \ufeffNama), sehingga perlu penanganan khusus.

⚠️ Karena BOM tidak kasat mata, masalahnya sering baru muncul ketika file dibuka di aplikasi lain — jangan heran jika file "tampak normal" di Notepad tetapi rusak di Excel, atau sebaliknya.

✅ Kapan Sebaiknya Pakai BOM

SituasiRekomendasi
CSV akan dibuka dengan Excel Windows oleh orang lainGunakan UTF-8 with BOM — paling aman.
CSV untuk diproses program (Python, database, API)UTF-8 tanpa BOM lebih umum dan bersih.
Berkas ASCII murni (hanya huruf/angka dasar)Tidak berpengaruh — BOM tidak diperlukan.
Data berisi karakter khusus (é, ü, emoji, aksara non-Latin)Wajib konsisten; pilih UTF-8 (opsional ber-BOM sesuai target pembaca).

Cara memeriksa BOM

# Lihat tiga byte pertama file (PowerShell)
Format-Hex data_mahasiswa.csv | Select-Object -First 1

# Ber-BOM    : EF BB BF 4E 61 6D 61 ...
# Tanpa BOM  : 4E 61 6D 61 3B ...

# Python: deteksi BOM
open('data_mahasiswa.csv', 'rb').read(3) == b'\xef\xbb\xbf'

🔤 Di Notepad: File → Save As → pilih Encoding: UTF-8 with BOM. Di VS Code: status bar encoding → Save with Encoding → UTF-8 with BOM.
