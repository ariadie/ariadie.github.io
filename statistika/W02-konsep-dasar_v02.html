01 — Pemantik

$p = 0{,}049$ vs $p = 0{,}051$: beda nasib?

"Satu koma empat persen — selisih nilai-$p$ dua studi replikasi. Satu terbit sebagai 'terbukti', satunya ditolak sebagai 'gagal'. Adil?"

Gambar di samping menunjukkan distribusi nilai-$p$ dari ribuan pengulangan: di bawah $H_0$ (ungu) ia seragam — nilai berapa pun sama mungkin muncul, termasuk $0{,}049$. Di bawah $H_1$ (hijau) ia menumpuk di dekat nol. Artinya: satu nilai-$p$ di dekat ambang hampir tidak membawa informasi — ia bisa berasal dari kedua dunia.

Pelajaran minggu ini: laporkan selalu selang kepercayaan + ukuran efek + kuasa di samping nilai-$p$, dan rencanakan $n$ sebelum mengambil data (Bagian 03).

Ilustrasi · sebaran nilai-$p$ di bawah $H_0$ vs $H_1$
Ungu = di bawah $H_0$ (seragam). Hijau = di bawah $H_1$ (menumpuk di nol). Garis oranye = ambang $\alpha = 0{,}05$.
02 — Tiga Pilar

Hipotesis, galat, dan dua dunia analisis

Tiga kartu di bawah adalah seluruh kosakata konseptual W04–W13.

Pilar 1 · Keputusan

$H_0$, $\alpha$, dan $\beta$

Tolak $H_0$ yang benar = galat tipe I ($\alpha$, kita tetapkan). Gagal menolak $H_0$ yang salah = galat tipe II ($\beta$). Lawan $\beta$ adalah kuasa $1-\beta$.

Pilar 2 · Bukti

Nilai-$p$ + selang + efek

Nilai-$p$ menjawab "seberapa aneh data ini jika $H_0$ benar" — bukan "berapa peluang $H_0$ benar". Selang kepercayaan menunjukkan rentang yang plausibel; ukuran efek menunjukkan besar praktisnya.

Pilar 3 · Dimensi

Univariat vs multivariat

Satu respons → uji-$t$, ANOVA, regresi (W04–W09, W12). Banyak respons berkorelasi → vektor rata-rata, MANOVA (W04–W06, W10–W11).

05 — Pendalaman

Kapan multivariat wajib?

Tiga jawaban jujur — bukan "selalu multivariat".

Wajib

Respons berkorelasi, pertanyaan bersama

Tekanan darah + kolesterol + gula sebagai profil risiko satu kesatuan → analisis bersama menjaga korelasinya (W10).

Cukup univariat

Satu pertanyaan, satu respons

"Apakah A* lebih cepat?" dengan satu ukuran waktu → uji-$t$/ANOVA. Multivariat di sini hanya menambah asumsi tanpa menambah jawaban.

Jembatan

ANOVA berulang → MANOVA

Menganalisis tiap respons satu per satu menggelembungkan galat (ingat FWER W03). MANOVA menguji vektor respons dalam satu kerangka.

06 — Contoh Terselesaikan

Uji satu populasi: klaim 120 menit

Contoh 1 · Data ilustratif (hipotetis)

Daya tahan baterai drone ($n = 10$): $\bar{x} = 118{,}5$ menit, $s = 4{,}2$ menit. Ujilah klaim pabrik $H_0: \mu = 120$ pada $\alpha = 5\%$ dua arah, lalu laporkan selang dan efeknya.

▸ Lihat langkah penyelesaian

1. Statistik uji. $\text{SE} = 4{,}2/\sqrt{10} = 1{,}33$; $t = (118{,}5-120)/1{,}33 = -1{,}13$; df $= 9$.

2. Keputusan. $t_{\text{kritis}} = \pm 2{,}26$. Karena $|-1{,}13| < 2{,}26$: gagal menolak $H_0$ — data konsisten dengan klaim 120 menit.

3. Selang + efek (yang wajib dilaporkan). CI$_{95\%} = 118{,}5 \pm 2{,}26\times1{,}33 = (115{,}5;\,121{,}5)$ — memuat 120, selaras dengan keputusan. $d = (118{,}5-120)/4{,}2 = -0{,}36$ (efek kecil-menengah).

4. Bacaan jujur. "Gagal menolak" bukan "membuktikan klaim benar" — dengan $n = 10$, kuasa untuk efek sekecil ini rendah. Cek di lab Bagian 03: $d = 0{,}36$, $n = 10$ memberi kuasa di bawah $0{,}30$.

08 — Reproduksibel Sejak Dini

Kode contoh Bagian 06

Pola kode untuk uji satu populasi (keluaran yang diharapkan: $t \approx -1{,}13$, $p \approx 0{,}29$ dua arah).

Python (scipy)

from scipy import stats
xbar, s, n, mu0 = 118.5, 4.2, 10, 120
se = s / (n ** 0.5)
t = (xbar - mu0) / se
p = 2 * (1 - stats.t.cdf(abs(t), n - 1))
print(f"t = {t:.2f}, p = {p:.2f}")

R

xbar <- 118.5; s <- 4.2; n <- 10; mu0 <- 120
se <- s / sqrt(n)
t <- (xbar - mu0) / se
p <- 2 * (1 - pt(abs(t), n - 1))
cat(sprintf("t = %.2f, p = %.2f\n", t, p))
  1. Hanya statistik ringkas yang dipakaiContoh ini memakai $\bar{x}$, $s$, $n$ — data mentah tidak diperlukan untuk uji satu populasi.
  2. Samakan definisi dua arahFaktor 2 pada nilai-$p$ wajib karena $H_1$ dua arah; uji satu arah menuntut justifikasi pra-data.
  3. Laporkan tiga serangkaiKeputusan + CI + $d$. Kode di atas mencetak dua yang pertama; $d$ satu baris tambahan.
